# 第一阶段实施计划（2026-10-12）

## 目标与边界

以根目录 SPEC.md 为需求基线，仅完成手机优先的可交互原型。用户已经确认技术栈与本阶段范围，直接实施，完成后等待验收。

- 首页：固定的 TOA / TDOA / RSS / AOA 四节点图谱，所有节点灰色「未测评」。
- 学习：模拟摘要、关键概念、原创简化示意、应用情境、练习/测试入口，标记待教师核验。
- 练习：每节点 1 道演示单选题（全部 4 道），服务端返回即时反馈，不更新等级。
- 测试演示：固定 4 道模拟题，切题与回看、全部答完后统一提交；答案在服务端，题目接口不返回答案。仅临时演示记录，不产生正式成绩。
- `/mistakes`、`/teacher` 为有解释的预留页，不虚构记录或统计，不提供未经鉴权的教师数据。
- 正式 20 题、随机 6 题、SQLite 持久化、累计等级、错题历史和教师统计未在本阶段实施。

## 目录与责任

```text
frontend/
  src/
    components/       图标、导航、图谱、概念示意、答题公共组件
    pages/            首页、学习、练习、测试和后续功能说明页
    data/             明确标记的模拟学习摘要
    lib/              /api/demo 服务适配与浏览器临时状态
    types.ts          节点、题目、作答、提交结果和后续领域类型
  package-lock.json   固定前端依赖
backend/
  app/
    main.py           /api 路由与构建产物同源托管
    demo.py           模拟题和内存演示尝试（线程锁保护提交）
    schemas.py        服务端输入/公开输出模型
    storage/README.md 后续 SQLite 表与事务契约
  tests/              接口与提交规则测试
scripts/              setup.ps1 / start.ps1 / dev-backend.ps1
docs/                 资料核对、扩展契约、验收记录
```

## 视觉方案

沿用参考图的蓝白学习界面，使用深蓝 #142c4f、交互蓝 #1765db、浅蓝 #eaf3ff、背景 #f4f7fb、正文灰 #53647b、未测评灰 #8b97a8。中文采用本地系统字体 Microsoft YaHei / PingFang SC，节点缩写采用 Bahnschrift / Segoe UI。用坐标网格与四节点连接表现“定位”，不复用校徽与二维码。

手机：单列内容、固定底部导航、大触控节点、选项整行可点；图谱是真实响应式布局。桌面：图谱与学习提示两栏，保留留白；学习和答题限制阅读宽度。图谱用 SVG 连线与 HTML 链接，无图谱重型依赖，无外部字体/CDN。
