# 21节点手机2D力导向图谱实施计划

依据用户新提供的《定位方法_2D知识图谱节点结构草案.md》，本轮替换3D方案。保留既有题库、后端、测试/评价/数据库边界，不开展正式业务阶段或公网部署。

## 目录与职责

```text
frontend/src/data/graph-structure.ts    21节点与22条有依据的关系，仅导航结构
frontend/src/data/knowledge-details.ts 16篇教材讲解、公式、原图引用及来源
frontend/src/data/comparisons.ts       两条跨分支比较的讲解
frontend/src/assets/textbook/          小范围教材原图/公式裁剪，按需加载
frontend/src/graph/model.ts            2D斥力、弹性连线、碰撞及平衡
frontend/src/graph/gestures.ts         单指拖节点/平移、双指缩放、点击阈值
frontend/src/graph/scene.ts            SVG场景与缩放平移，按需刷新
frontend/src/components/LearningSheet.tsx 移动端教材/概览/比较内容
scripts/mobile-2d-qa.mjs               375/390/430触屏回归
```

## 实施顺序

1. 验证草案全部21节点ID/标签、20条层级关系和2条必备比较关系，不采用可选第三条。先测拓扑数量/不重复/父子归属、指针操作和二维力收敛，再实现SVG力图。
2. 全部默认展示，无展开状态。节点位置由真实二维力模拟决定；单指命中节点直接拖动，空白拖动平移，双指以中心点缩放/平移；移动8px以上不作为点击。松手继续平衡，空闲暂停动画。复位适应全部节点；提供缩放按钮。
3. 模块点击打开包含四个概念入口的概览及原模块练习入口。16个概念和2条比较说明打开底部阅读面板，关闭保持视图。结构不包含正文或概念等级，模块状态通过独立适配器读取现有后端结果；没有正式记录时保留未测评。
4. 逐条核对PDF8–11页，补全16篇内容；从PDF局部渲染原图3-2/3-3/3-4/3-6及有必要的公式，资源放在Vite assets目录经构建托管，不改变后端静态路由。页面标记教材整理待教师核验，保留扫描页/印刷页/章节。
5. 三个竖屏尺寸测试初始21节点、拖拽/排斥/连线动态、缩放平移可达全部节点、模块不折叠、两条比较、全部16内容、图片加载、返回保留视角。回归现有练习/测试，构建和后端测试通过，核对哈希。

## 回退与运行

当前3D源码及依赖备份在tmp/rollback-2d。需要回退时先备份当前2D成果，将该目录的src和package文件恢复到frontend；移除本轮新增的结构/比较数据、状态适配器与assets/textbook，npm.cmd ci后重新构建。保留教材、草案和后端原件。

继续使用Windows PowerShell的scripts/start.ps1，localhost:8000本地验收。所有手机浏览器仿真结果与微信实机兼容性分开记录。
