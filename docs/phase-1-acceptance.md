# 第一阶段验收记录

日期：2026-10-12。状态：开发与本地验证完成，等待用户验收，未进入第二阶段。

## 交付范围

- React + TypeScript + Vite、FastAPI本地骨架与单端口预览。
- 四节点图谱、四个模拟学习页、全节点/单节点练习、统一提交的测试演示及结果复习。
- 首页和页面持续标记第一阶段模拟数据；4道固定模拟题，不伪装为正式20题题库/随机6题。
- 全部节点保持未测评；不存在学生节点百分数、虚构统计或正式学习记录。
- Windows安装、启动、停止、回退说明；正式SQLite、20题、随机6题、累计等级、错题历史、教师鉴权与统计均有扩展契约。

## 实际验证

| 项目 | 结果 |
| --- | --- |
| Windows setup.ps1 | 按锁文件安装并构建成功 |
| TypeScript + Vite生产构建 | 成功 |
| Python依赖一致性（pip check） | 无冲突 |
| 后端pytest | 6项通过，无警告 |
| start.ps1 -Port 8001 -SkipBuild | 启动成功，健康接口返回200；备用服务已停止 |
| stop-preview.ps1 | 验证当前项目进程树后停止成功，8000端口释放；已重新启动预览 |
| 四节点跳转 | TOA/TDOA/RSS/AOA均到达相应学习页，可返回图谱 |
| 路由焦点 | 切换后从页面顶部显示，不跳过标题栏 |
| 单节点练习 | 选择、检查、反馈、完成和再练通过 |
| 全部练习 | 四题切换、即时对错及解析、完成和重新练习通过 |
| 测试未答完 | 最后一题提交按钮禁用，可返回补答 |
| 测试刷新 | 冻结题目与当前答案恢复；可修改答案 |
| 服务端判分 | 演示中故意错1题，返回3/4；统一提交后显示4题解析 |
| 结果刷新 | 保留原始错误选项与正确答案，不覆盖作答 |
| 等级隔离 | 演示后四节点仍为未测评 |
| 断网重试 | 启动失败展示错误；恢复网络后可再点击启动 |
| 服务重启后的恢复 | 显示“演示测试已失效”，可明确重新开始，不伪装成已持久化记录 |
| 响应式 | 320/390/768/1440px，9个主要路由均无横向溢出 |

后端6项覆盖：公开题目无答案/解析、四节点演示结构；未完成与非法选项不能提交；幂等提交保留原答案；不同尝试令牌隔离；练习后端判分；未知API和源文件路径不泄露。测试先在空API骨架出现6项失败，实现后通过。

浏览器使用真实Chromium自动操作与截图审阅。过程中用于截图的有界面浏览器偶发超时，改用无界面Chromium完成最终截图与相同交互检查；不据此宣称在真实手机硬件或移动网络上验收通过。正常页面检查无脚本异常；刻意断网/重启产生的网络失败用于验证提示。
