# 给 Codex 的交接包

这是项目启动资料，不是已经完成的网站。包含已经确认的需求、开发约束、教材扫描和界面参考图片。

## Windows 本地启动 Codex 前

1. 解压整个文件夹到例如 `C:\Projects\knowledge-map`（路径可以自行决定）。
2. 在 VS Code/Codex 中 **打开该文件夹作为项目根目录**，使 Codex 能看到 `SPEC.md`、`AGENTS.md`、`source-materials/` 和 `references/`。
3. 把下面提示词发给 Codex。**不要只粘贴此前聊天记录**：项目需求以 `SPEC.md` 为准。
4. 让 Codex 先给出阶段计划并只完成第一阶段，之后再验收第二阶段。

## 发给 Codex 的第一条指令（可复制）

你现在负责开发《定位方法》知识图谱互动学习平台V1。请先阅读项目根目录的 SPEC.md 和 AGENTS.md，检查 source-materials 下的教材扫描PDF，以及 references 下的两张界面参考图。这些文件是本项目唯一的已提供课程依据和界面参考。

按已确认需求实现：学生先进入四节点知识图谱，点击TOA/TDOA/RSS/AOA学习；固定20道单选题，每模块5题；全量刷题即时反馈但不影响等级；正式测试每次随机抽取6题且覆盖四节点，完成后统一判分；每个节点独立按历次正式测试累计正确次数/累计作答次数，划分未测评、不熟练、熟悉、了解、掌握，并在图谱中仅显示等级、不显示百分数；有历史错题与解析、简化的教师统计。首版Windows本地运行，计划使用cpolar对外访问2-3天，不买域名、不备案、不依赖云数据库。

技术方案建议React + TypeScript + FastAPI + SQLite，手机端优先。请不要一次做完所有功能，先：
1）核对需求并列出仍需教师审核的教材/题目内容；
2）给出简明开发计划与项目目录；
3）只实施第一阶段：知识图谱及学习/练习/测试基本页面的前端可运行原型，使用明确标识的模拟数据；
4）启动运行并告知我在Windows上如何查看和验收。

在第一阶段通过之前，不要擅自增加AI、RAG、用户注册、第二套题库、复杂后台、云服务或对外部署。

- `SPEC.md` 中的20题尚不是现成的教师审定题库；Codex应先拟题供核对，不能直接标为“正式已验证”。
