# 手机2D知识图谱验收记录

本轮按《定位方法_2D知识图谱节点结构草案.md》重构；此前3D方案已被本轮用户要求替代。仍处于第一阶段，等待用户验收。

## 交付结构

- 21个节点全部默认展示：1中心、4模块、16教材知识点。没有折叠或三维依赖。
- 20条层级实线；2条淡色比较虚线：TOA-2↔TDOA-2、TOA-4↔TDOA-4。没有新增随机连线或可选第三条比较。
- d3-force二维斥力、弹性连线、碰撞及弱向心力；SVG渲染。拖动改变节点坐标，松手继续平衡，稳定后停止帧循环。最高约30帧/秒，打开面板或隐藏页面时暂停。
- 单指拖节点、空白平移、双指缩放/平移、缩放按钮及适应全部。节点拖至远处仍可复位到全部节点的包围盒；控制按钮位于图谱触控区域之外。
- 16篇教材讲解独立于图谱结构，包含来源、条件、公式和按需加载的原图。两条关系另有比较说明。原 `/learn/:nodeId` 路径复用同一份知识内容。
- 学习等级只显示在四个一级节点，读现有后端结果；当前演示后端返回未测评。二级节点不绑定题目或评价。
