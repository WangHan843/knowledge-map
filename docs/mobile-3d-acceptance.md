# 手机 3D 图谱验收记录

日期：2026-10-12。范围：第一阶段的手机图谱交互重构，等待用户验收，不进入第二阶段。

## 交付

- Three.js 透视场景 + d3-force-3d 三维力布局。中心“定位方法”和四个模块，默认 5 节点；一次展开一个模块的 3 个教材子节点，最多 8 节点、7 连线。
- 单指旋转、双指捏合缩放、双指同向拖动平移；450ms 长按后沿当前相机平面移动节点，中心也可拖动。旋转后可调整另一空间方向，释放后继续力布局。
- 12 个教材子节点打开 Bottom Sheet，支持独立纵向滚动，展示原理、公式、示意图、扫描/印刷页码。关闭保留图谱实例和相机。内容标注“教材整理 · 待教师核验”，子节点没有等级或题目。
- 复位适配当前分支；切换模块自动重新取景。图谱区域不滚动整页，面板单独滚动。四个模块仍为“未测评”。

## 其他回归

- 生产构建通过；10 项前端手势/拓扑/三维模拟测试通过；6 项原有后端接口测试通过。
- 模拟测试：未答完不能提交，答中不显示答案，刷新恢复当前答卷和选项，允许修改答案，后端返回预期 3/4 结果，刷新后原始选择仍保留，首页四个状态仍为未测评。
- 自主练习选择、确认和解析正常。离开图谱后 canvas 数量为 0，恢复普通页面滚动；返回正常创建。
- 键盘 Enter/Space 打开节点，面板 Tab 焦点限制和 Escape 关闭正常；重试按钮键盘激活正常。
- 使用 WEBGL_lose_context 注入画布中断：明确提示、隐藏失效场景、复位禁用；重试后仅一个 canvas 和 5 节点。没有静态 2D 替代图。
- 用真实缩放/旋转把 AOA 移至相机后，确认 hidden 标签的计算样式是 display:none。已修复审查发现的 display:flex 覆盖隐藏样式问题。
- 连续手势/滚动后发现兼容 click 偶发缺失；复位、帮助、关闭及重试采用有效 pointerup 激活，过滤兼容 click 重复触发，保留键盘/辅助技术激活、禁用和取消判断。
- 稳定后的状态为 idle。一次本机 Chromium Performance 的 1 秒采样，主线程 TaskDuration 增量约 0.194ms；它是本机空闲检查，不代表手机帧率、电量或微信性能。
- 完成独立代码审查；后端 demo/main/tests、Test.tsx、Practice.tsx 的 SHA256 与重构前备份一致。

## 性能与兼容性边界

低细分球体、无阴影/后处理、像素比上限 1.5、活跃更新上限约 30fps；模拟收敛后停止帧调度，面板打开和 document.hidden 时暂停；退出路由释放几何、材质、事件和 WebGL 上下文。三维引擎延迟加载，构建包约 574kB（gzip 约146kB，当前本地 HTTP 默认未压缩）。

**未实测 iOS/Android 手机、微信内置浏览器、低端 GPU、移动网络或后台切换耗电。** 本机 headless 新标签页没有改变 document.hidden，因此后台隐藏逻辑仅完成代码检查，不能声称完成真机后台验证。当前 Three.js 要求 WebGL2，旧 WebView 不支持时给出错误提示和重试。没有开通 cpolar、公网部署或改动二维码。

## 查看与复现

本地页面：`http://localhost:8000/`。浏览器 F12 → 设备工具栏可选择上述尺寸。后台预览已经运行时直接刷新。停止后重新启动：

```powershell
Set-Location D:\knowledge-map
powershell -ExecutionPolicy Bypass -File .\scripts\start.ps1
```

触屏回归（先启动 8000 服务）：

```powershell
Set-Location D:\knowledge-map\frontend
npm.cmd exec -- playwright install chromium
npm.cmd run test:mobile
```
